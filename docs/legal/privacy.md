# Privacy

Hot Rodding History is a free, static website. You can read it without creating an account. We do not run ads, and we do not sell your information.

This page describes what we actually collect today. If that changes, we will update it and change the date at the bottom.

## Analytics

Cloudflare Web Analytics can be turned on to see, in aggregate, how the site is used and how pages perform. The script is included in the site footer only when a token is set. It is not on the page while that token is empty.

Cloudflare's own documentation for this product, as of the date we checked (November 23, 2026), says:

- It does not use client-side state such as cookies or localStorage to collect usage metrics.
- It does not "fingerprint" individuals via IP address, User Agent string, or any other data for the purpose of displaying analytics.
- It does not track individual end users across Cloudflare customers' Internet properties.
- It collects the minimum amount of information — timing metrics — to show how websites perform, and Cloudflare states that Web Analytics does not collect or use visitors' personal data.
- For the related RUM beacon, Cloudflare states that the visitor's IP address is discarded at the nearest data center and is not stored in core databases or logs, and that the script does not store or access cookies, localStorage, sessionStorage or IndexedDB.

We checked Cloudflare's Web Analytics product page and developer documentation. We are not repeating claims we did not find there. Cloudflare's descriptions may change; their current pages are [cloudflare.com/web-analytics](https://www.cloudflare.com/web-analytics/) and [Data origin and collection](https://developers.cloudflare.com/web-analytics/data-metrics/data-origin-and-collection/).

## Hosting

The site is hosted on Cloudflare Pages. To deliver a page, Cloudflare receives the ordinary technical information involved in an HTTP request, such as your IP address, the page you asked for, and your browser's user agent. Cloudflare uses that information to operate and secure the host. We have not set up any extra visitor-log export (for example, Logpush).

!!! warning "To be completed before launch"
    Confirm with the person who runs the Cloudflare account that no retained request-log export is on.

How Cloudflare handles data in its role as host is described in [Cloudflare's privacy policy](https://www.cloudflare.com/privacypolicy/).

## Forms and accounts

This site has no accounts and no form that collects your name or email. The only on-page "forms" are local filters (for example, filtering a list of stories). They stay in your browser and are not submitted to us.

Reader mail, corrections, sources and suggestions go by email, from your own mail program, to the address above.
