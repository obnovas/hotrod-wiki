# Quick Answers: The Questions That Connect the Dots

*The short version first, then the full story.*

Each answer here is a few sentences long and says only what its article says, with the same hedges. A ⚠ means the sources disagree and a ◐ means we have only one source; either one links to the article's Open questions. For the evidence, follow the **Full story** link. Each question has its own address, so you can link straight to it.

<!-- hr:quick-answers -->

*How this page is kept:* the answers live in `docs/data/quick_answers.yml`, and the build checks every one of them. Each number must appear in the linked article, each link and anchor must resolve, and each ⚠ or ◐ must still match an open item in the article. When an article settles a question, the build fails until its answer here is updated. See [CONTRIBUTING](https://github.com/obnovas/hotrod-wiki/blob/main/CONTRIBUTING.md#quick-answers) and the [Research Trail](../research-trail.md#standing-standard-for-every-nightly-round-set-in-round-11).
